Build Roadmap — 4 Phases

PHASE 1 Foundation

Core Platform

  • ▸ User registration (OTP + Google OAuth)
  • ▸ Database schema: Users, Tournaments, Entries, Leaderboard, Rebates
  • ▸ Admin dashboard — full CRUD on all entities
  • ▸ Waitlist system → auto-approve/invite flow
  • ▸ Discord bot integration (auto-role on join)

Build time: ~1-2 weeks · Base44 backend + entities

PHASE 2 Tournament Engine

Competition System

  • ▸ Tournament creation & scheduling (bi-weekly auto-cycle)
  • ▸ Trade submission/verification system
  • ▸ Live leaderboard with real-time ranking
  • ▸ Rebate calculator engine (admin-configurable rates)
  • ▸ "Rex" AI assistant — stats analysis, tips, match recaps
  • ▸ Arena system (multiple trading categories/leagues)

Build time: ~2-3 weeks · Backend functions + automation

PHASE 3 Growth

Engagement & Monetization

  • ▸ Referral system (invite links → bonus rebates)
  • ▸ User profiles — stats, rank history, achievements
  • ▸ Achievement/badge system (streaks, milestones)
  • ▸ Payment integration — entry fees, premium tiers
  • ▸ Email/notification system — match alerts, results
  • ▸ Sponsorship slots (branded tournaments)

Build time: ~2 weeks · Payments + notifications

PHASE 4 Scale

Autonomous Operations

  • ▸ Automated tournament lifecycle (create → run → rank → reward → archive)
  • ▸ Broker API integration (auto-verify trades)
  • ▸ AI agent for Discord community management (Rex bot)
  • ▸ Weekly analytics dashboard (retention, revenue, engagement)
  • ▸ Anti-cheat system (trade verification, pattern detection)
  • ▸ Mobile app / PWA

Build time: ~3-4 weeks · Automation + AI agents

Database Schema (Base44 Entities)

User

id, email, phone, name, discord_id, broker_connected, tier, total_rebates, rank, created_date

Tournament

id, name, arena, start_date, end_date, status, entry_fee, prize_pool, rebate_rate, max_participants

Entry

id, user_id, tournament_id, trades[], pnl, rank, rebate_amount, status

Trade

id, entry_id, asset, direction, entry_price, exit_price, size, pnl, timestamp, verified

Leaderboard

id, tournament_id, rankings[{user_id, rank, pnl, rebate}], updated_date

Waitlist

id, email, phone, referred_by, invite_code, status, joined_date

Rebate

id, user_id, tournament_id, amount, rate, status, paid_date

Arena

id, name, category, rules, min_tier, active

AdminConfig

id, key, value, updated_by — all platform variables (rates, fees, caps)

Operations — How It Runs

Automated (Workflows)

  • • Bi-weekly tournament auto-creation (cron)
  • • Leaderboard recalculation every X hours
  • • Rebate distribution on tournament end
  • • Discord role updates on rank change
  • • Email notifications: match start, results, payouts
  • • Waitlist → invite batch sending

Manual (Admin Dashboard)

  • • Adjust rebate rates per tournament
  • • Override prize pools and entry fees
  • • Approve/verify large payouts
  • • Create custom arenas and rules
  • • Ban/dispute resolution
  • • Sponsorship configuration
